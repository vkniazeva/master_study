# Fresh Food Demand Forecasting for Airline Retail

A machine learning project focused on **fresh food demand forecasting for airlines**, developed as part of my Master’s thesis in Data Science & AI.

The project addresses a specific challenge in airline retail: predicting demand for fresh food products in an environment with highly sparse sales data, limited historical observations, and a large number of zero-sales records.

The solution combines exploratory data analysis, feature engineering, classification and regression approaches to predict whether a product will be sold and estimate the expected quantity.

In the pilot evaluation, the solution reduced **estimated food waste from 46% to 7%**, demonstrating the potential of machine learning to address a real operational problem in airline catering and retail.

The repository contains the research, data preparation and modelling pipeline, together with the final presentation of the project.

**Key areas:** Machine Learning · Demand Forecasting · Airline Retail · Food Waste Reduction · Data Science · Predictive Analytics
